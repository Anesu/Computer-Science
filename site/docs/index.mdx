# Open CS Degree 2026

A complete, modern computer-science degree built as **curriculum-as-data**: an
ACM/IEEE CS2023-aligned pathway of 45 courses across 8 semesters and 3 tracks
(AI, Systems, Security), stored in the Open Knowledge Format and delivered
lesson-by-lesson through `/teach`.

## How this campus works

- **[Dashboard](/dashboard/)** — your progress, the frontier of what you can
  study next, credits, and knowledge-area coverage. Exports `progress.yaml`.
- **[Course catalog](/courses/)** — all 45 courses; every page ends with a
  ready-to-paste `/teach` mission.
- **[Pathway map](/pathway/)** — the prerequisite DAG with your progress
  overlaid. (For the click-to-explore canvas, open `planning/pathway.tldraw`
  in tldraw Desktop.)
- **[Library](/library/)** — every cited source and its license status.
- **Tracks** — [AI](/tracks/ai/) · [Systems](/tracks/systems/) ·
  [Security](/tracks/security/).
- **`/teach`** delivers the lessons — it reads the same Markdown corpus this
  site renders (every page is raw Markdown at `<path>.md`, and the build
  emits `llms.txt`).

## Programme shape

| | |
|---|---|
| Semesters | 8 |
| Courses | 45 (26 core) |
| Core credits | 95 |
| Tracks | AI · Systems · Security |
| Capstone | Two-semester project (S7–S8) |

The curriculum source of truth is `curriculum/pathway.yaml`; everything else —
this site, the canvas, the validator — is generated from or checked against it.
