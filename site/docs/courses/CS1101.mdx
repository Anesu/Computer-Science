# CS1101 — Programming Fundamentals

Semester 1 · Core · 4 credits

## Overview

Programming as the discipline of expressing ideas precisely enough for a
machine to execute — and clearly enough for a person to maintain. The course
moves from values and expressions through control flow, functions, and
recursion to the first honest project, all in Python. It is deliberately the
pathway's first course: every later course assumes the habits built here,
especially decomposing a problem before typing and predicting what code does
before running it.

Covers CS2023 knowledge areas: SDF (Software Development Fundamentals), SEP
(Society, Ethics and the Profession).

## Prerequisites

None — this course starts the pathway.
