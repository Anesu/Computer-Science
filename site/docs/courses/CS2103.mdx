# CS2103 — Software Engineering

Semester 3 · Core · 4 credits

## Overview

Covers CS2023 knowledge areas: SE (Software Engineering), SEP (Society, Ethics and the Profession).

## Prerequisites

- [CS1203 — Software Construction & Tooling](/courses/CS1203/)

## Unlocks

- [CS3202 — LLM Application Engineering](/courses/CS3202/)
- [CS3203 — Large-Scale Software & DevOps](/courses/CS3203/)
- [CS4101 — Computing, Ethics & Society](/courses/CS4101/)
- [SEC-SSD — Secure Software Development](/courses/SEC-SSD/)

## Units

1. Complexity and modular design — _Phase 3_
2. API and interface design — _Phase 3_
3. Testing strategy: unit, integration, end-to-end — _Phase 3_
4. Code review and collaboration workflows — _Phase 3_
5. Refactoring and technical debt — _Phase 3_
6. Engineering at scale: CI/CD, versioning, releases — _Phase 3_
7. Requirements, architecture, and documentation — _Phase 3_
8. Professional practice and ethics — _Phase 3_

## Reading list

- **A Philosophy of Software Design (2nd ed.)** — John Ousterhout (`aposd`, status: identified)
- **The Pragmatic Programmer (20th Anniversary ed.)** — David Thomas, Andrew Hunt (`pragprog`, status: ingested)
- **Software Engineering at Google** — Titus Winters, Tom Manshreck, Hyrum Wright (`swe-google`, status: open)
