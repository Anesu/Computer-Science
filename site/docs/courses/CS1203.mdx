# CS1203 — Software Construction & Tooling

Semester 2 · Core · 4 credits

## Overview

Covers CS2023 knowledge areas: SDF (Software Development Fundamentals), SE (Software Engineering), SPD (Specialized Platform Development).

## Prerequisites

- [CS1101 — Programming Fundamentals](/courses/CS1101/)

## Unlocks

- [CS2103 — Software Engineering](/courses/CS2103/)
- [CS2204 — HCI & Visual Computing](/courses/CS2204/)
- [EL-MOBILE — Mobile & Cross-Platform Development](/courses/EL-MOBILE/)

## Units

1. The Unix shell and scripting — _Phase 3_
2. Editors and development environments — _Phase 3_
3. Version control with Git — _Phase 3_
4. Data wrangling on the command line — _Phase 3_
5. Debugging and profiling — _Phase 3_
6. Automated testing — _Phase 3_
7. Build systems, packages, and releases — _Phase 3_
8. Security hygiene for developers — _Phase 3_

## Reading list

- **The Pragmatic Programmer (20th Anniversary ed.)** — David Thomas, Andrew Hunt (`pragprog`, status: ingested)
- **Pro Git (2nd ed.)** — Scott Chacon, Ben Straub (`pro-git`, status: open)
- **The Missing Semester of Your CS Education** — Anish Athalye, Jon Gjengset, Jose Javier Gonzalez Ortiz (`mooc-missing-sem`, status: open)
