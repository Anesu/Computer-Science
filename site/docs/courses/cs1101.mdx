## What you'll learn

Programs as data transformation: values, control flow, functions, recursion,
basic data structures, and the discipline of decomposing a problem before
typing. Taught in Python.

## Units

1. Values, types, and expressions
2. Control flow and iteration
3. Functions and decomposition
4. Recursion
5. Collections: lists, dicts, sets
6. Files and errors
7. A first project
